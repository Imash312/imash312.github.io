Вход в админку

Админка сохраняет изменения прямо в ваш репозиторий на GitHub. Для входа нужен личный ключ доступа (token). Он хранится только в этом браузере.

Как получить ключ доступа (один раз)
  1. Откройте github.com/settings/personal-access-tokens/new.
  2. Token name: «Портфолио админка». Expiration: срок по желанию.
  3. Repository access → Only select repositories → выберите imash312.github.io.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Нажмите Generate token, скопируйте ключ и вставьте сюда.

Короткие ролики для блока «Рекламные ролики». Лучше всего вертикальное видео до 15 секунд и до 20 МБ — оно крутится без звука.

Загрузить весь сайт из папки

Выберите папку сайта на компьютере (например, site на рабочем столе). Все файлы из неё будут загружены в репозиторий одним коммитом с сохранением путей. Используйте это для первой загрузки или чтобы заменить сайт целиком.
